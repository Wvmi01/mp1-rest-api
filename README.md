## MP2 Rest API
This project uses FastAPI to create a REST API with different endpoints for checking the API's status, uploading CSV files, retrieving datasets, and processing data. It builds on MP1 by reusing the existing functions for data validation, removing duplicates, handling missing values, and removing outliers. The uploaded datasets are stored in memory and can be accessed using their assigned IDs. The project also uses Pydantic models to organize and validate requests and responses. It uses middleware to log HTTP requests and errors, and pytest to test whether the API works as expected.
